객실 유형

검색 결과에서 무엇을 비교할지 정할 수 있어요.

객실 유형은 침대 구성, 크기, 정원처럼 방 자체의 특징을 묶은 분류예요. 요금에 포함된 서비스와는 구분해서 보는 편이 좋아요.

예시 · 같은 2인 객실도 더블 침대 1개와 싱글 침대 2개로 나눌 수 있어요.

취소와 환불

예약 전에 사용자가 확인해야 할 조건을 놓치지 않게 해요.

취소 가능 여부만으로는 조건을 다 설명할 수 없어요. 무료 취소 기한과 이후 수수료가 어떻게 달라지는지도 확인해야 해요.

가상의 정책 · 지정한 날짜 전에는 무료, 이후에는 별도 수수료. 실제 조건은 숙소와 상품마다 달라요.

예약의 흐름

검색 화면이 전체 여정에서 어떤 역할을 하는지 알 수 있어요.

사용자는 조건을 정하고, 상품을 비교하고, 예약 정보를 입력해요. 각 단계에서 앞서 선택한 날짜와 상품 조건을 이어 보여주면 확인하기 쉬워요.

간단한 흐름 · 검색 → 상품 선택 → 정보 입력 → 예약 확인
